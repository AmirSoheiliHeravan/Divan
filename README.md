# دیوان (Divan) — حسابدار شخصی و خانوادگی

اپلیکیشن اندرویدی برای مدیریت کامل مالی شخصی و خانوادگی؛ آفلاین‌محور، با پشتیبانی از پیامک بانک‌های ایرانی، ویجت‌های صفحه اصلی و نسخه ساعت هوشمند (Wear OS).

---

## امکانات

### هسته مالی
- **حساب‌ها و کیف پول‌ها**: ۱۴ نوع حساب (جاری، پس‌انداز، ارزی، کارت، نقد، کیف پول دیجیتال، صندوق خانوادگی، مشترک، هدفمند، سرمایه‌گذاری، امانی، بدهی/مطالبات، تسویه، سفارشی) با موجودی افتتاحیه، حداقل موجودی، ۴ رقم آخر کارت و وضعیت فعال/بسته/آرشیو
- **تراکنش‌ها**: درآمد، هزینه، انتقال بین حساب‌ها + انواع دیگر مثل دریافت وام، بازپرداخت، بدهی/طلب، پس‌انداز، سرمایه‌گذاری، خرید/فروش دارایی، اصلاح موجودی و کارمزد
- **دسته‌بندی‌ها**: ۱۵ گروه اصلی با بیش از ۱۱۰ زیردسته آماده + دسته سفارشی نامحدود + امکان مخفی‌سازی
- **چندارزی**: ۱۵ ارز استاندارد با پایه ریال (IRR) + ارز سفارشی، ثبت نرخ دستی با تاریخ و نگهداری نرخ تاریخی هر تراکنش
- **دقت مبالغ**: ذخیره‌سازی عدد صحیح در کوچک‌ترین واحد (بدون خطای اعشاری)، ورودی با ارقام فارسی/عربی

### ماژول‌های تخصصی
- **وام و اقساط**: قرارداد با ۳ روش سود (بدون سود، ثابت/FLAT، مستهلک‌شونده)، تولید خودکار جدول اقساط، پرداخت کامل/جزئی با جلوگیری از تکرار
- **بدهی و طلب**: دفتر «من بدهکارم / به من بدهکارند» با پرداخت جزئی و تسویه خودکار
- **چک‌ها**: چک دریافتی/پرداختی با وضعیت‌های کامل؛ وصول چک، تراکنش واقعی می‌سازد
- **بودجه**: بودجه ماهانه کلی یا هر دسته با درصد مصرف، نوار پیشرفت و اعلان هشدار
- **پرداخت‌های دوره‌ای**: قالب‌های تکرارشونده روز/هفته/ماه/سال با کلید ضدتکرار
- **کالا و انبار**: بارکد/SKU، حداقل موجودی با هشدار، انقضا، حرکت موجودی و میانگین موزون بهای تمام‌شده
- **فاکتور چندقلمی**: تخفیف/مالیات/حمل، پرداخت کامل/جزئی/اعتباری، ثبت خودکار موجودی و ساخت بدهی برای مانده
- **اموال و دارایی**: خرید با ثبت مالی، ارزش تخمینی، بیمه، فروش با تراکنش درآمد
- **خانواده**: اعضا با نقش (مالک، مدیر، مدیر مالی، عضو، فقط‌خواندنی، کودک)
- **طرف‌حساب‌ها**: شخص/فروشگاه/بانک/شرکت + اتصال به مخاطبین گوشی
- **گزارش‌ها**: بازه‌های زمانی، فیلتر عضو، نمودار دایره‌ای، مقایسه ماه‌ها و خروجی CSV سازگار با Excel فارسی

### قابلیت‌های شاخص
- **پیامک بانک‌های ایرانی**: قواعد آماده برای ۲۲ شماره فرستنده رایج (ملی، ملت، صادرات، تجارت، رفاه، مسکن، کشاورزی، پارسیان، پاسارگاد، سامان، سپه، شهر، آینده، کوثر، انصار، سرمایه، کارآفرین، مهرایران و...) — پارسر با Regex نام‌دار (amount/card/account/balance)، نرمال‌سازی ارقام فارسی، تشخیص جهت با کلیدواژه، اتصال حساب با ۴ رقم آخر کارت و جلوگیری از ثبت تکراری
- **افزودن بانک هر کشور**: از تنظیمات با شماره فرستنده و الگوی دلخواه + دکمه تست زنده الگو
- **ویزارد راه‌اندازی**: زبان، ارز پایه، اعضای خانواده، حساب اول، دسته‌بندی‌ها، دسترسی‌ها و PIN — همه بعداً از تنظیمات قابل تغییر
- **سینک تقویم گوشی**: سررسید اقساط و چک‌ها به‌صورت رویداد در تقویم سیستم‌عامل
- **ویجت‌ها**: «ثبت سریع» (هزینه/درآمد/انتقال + خلاصه ماه) و «موجودی» (موجودی کل + درآمد/هزینه ماه)
- **Wear OS**: موجودی، خلاصه ماه و ثبت هزینه مستقیم روی ساعت با همگام‌سازی از طریق Data Layer API

### زیرساخت
- کاملاً آفلاین با Room/SQLite؛ UI همیشه با دیتابیس محلی کار می‌کند
- صف همگام‌سازی با `idempotency key` یکتا و ارسال به `POST api/v1/sync/batch` پس از تنظیم آدرس سرور
- لاگ کامل عملیات در `audit_log` + حذف نرم با نسخه رکورد
- پشتیبان‌گیری JSON با رمزگذاری اختیاری AES-256-GCM (PBKDF2)
- قفل PIN (PBKDF2) + زیست‌سنجی، زبان مستقل هر کاربر، ۴ زبان fa/en/de/tr

## ساختار پروژه

```
Divan/
├── app/                        ← اپ گوشی (Kotlin + Jetpack Compose)
│   └── src/main/java/com/divan/app/
│       ├── core/               ← db (Room)، money، sms، sync، backup،
│       │                          calendar، contacts، security، notify، work
│       ├── data/               ← Repositories
│       ├── ui/                 ← Compose screens (داشبورد، تمام ماژول‌ها)
│       ├── widget/             ← ویجت‌های Glance
│       └── wear/               ← سرویس گوشی برای ارتباط با ساعت
└── wear/                       ← اپ ساعت (Compose for Wear)
```

## ساخت و اجرا

**پیش‌نیاز**: Android Studio Koala یا جدیدتر + JDK 17

1. پروژه را باز کنید: `File → Open → Divan`
2. منتظر Sync بمانید (Gradle 8.7 و وابستگی‌ها خودکار دانلود می‌شوند)
3. `Run ▶` روی ماژول `app`
4. نسخه ساعت: کانفیگ `wear` را روی ساعت یا شبیه‌ساز Wear OS اجرا کنید
5. خروجی نهایی: `Build → Generate Signed App Bundle / APK`

## اولین اجرا
ویزارد شروع می‌شود: زبان ← ارز (ریال پیش‌فرض) ← نام خانواده و اعضا ← حساب اول (برای حساب بانکی، ۴ رقم آخر کارت را وارد کنید تا پیامک‌ها خودکار وصل شوند) ← دسته‌بندی‌ها ← دسترسی‌ها ← PIN.

## تنظیم پیامک بانکی
`تنظیمات → پیامک بانکی`:
- کلید «خواندن پیامک بانک‌ها» را روشن و مجوز بدهید
- اگر پیامک بانک شما تشخیص داده نشد: `قواعد بانک‌ها → افزودن بانک جدید`؛ شماره فرستنده، الگو و یک پیامک نمونه بدهید و تست الگو را بزنید
- «ثبت خودکار» خاموش یعنی هر تراکنش پیامکی اول تأیید شما را می‌خواهد (پیش‌فرض)

## یادداشت‌های فنی
- مبالغ با `Long` در کوچک‌ترین واحد؛ تبدیل ارز با `BigDecimal` و گرد کردن HALF_UP
- هر تراکنش نرخ تبدیل لحظه ثبت (`rateUsed`) را نگه می‌دارد
- زبان‌ها در `strings.xml`؛ جهت RTL خودکار
- قرارداد سرور همگام‌سازی در `core/sync/SyncApi.kt` (پیشنهادی: FastAPI + PostgreSQL)
